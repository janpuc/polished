# polished design spec v3, phase 1: the self-hosted web app, beautiful on iPhone, iPad and Mac

2026-10-26. Author: Fable (oracle). Scope: the app as deployed today (FastAPI + Jinja + HTMX, Pocket ID, Holo Taco), for one user on three devices. Prototype evidence is in `~/.cache/polished/fable-v3/` (HTML in the root, screenshots in `shots/`, candidate fonts in `fonts/`, real tip SVGs in `tips/`); copy `shots/` somewhere durable if it should outlive a reboot. No repo file was changed by this session.

**Contract kept:** Operate surface; no build step; CSP without inline style or script; `tips.py` tips are the identity of a shade; the swatch book palette (hue 335, ink and board, pink means wanted, foil only on tips and the logo); one filled action per view; sentence case, no eyebrows, no middle dots; one `#sheet` dialog; sync etiquette; public repo with no personal data. **Revised on evidence:** "SF Pro only" becomes SF for UI plus one display face in four roles; "no shadows" becomes "no card shadows, but tips cast a contact shadow"; wheels become deletable with confirmation (Jan's decision, backend in flight).

| 8 | Aesthetic | 2 | see below |
| 9 | Recovery | 3 | |
| 10 | Help | 2 | tag page only |
| | Total | **26/40** | Acceptable |

Specificity: the tips make it this app, but they are decals, not objects, and the rest is a well-made iOS settings app in plum. Why it stops at pretty:

- **Tips have no light.** One 125° gloss and a 1px mat on every tip; nothing casts a shadow or has an edge against the board. `shots/p1-lit-tips-light.png` row A (current) against row B: the same SVGs, and only B reads as painted nails on paper.
- **One voice.** SF Pro 700 for the wordmark, titles, shade names and the hub number. Nothing was lettered. `shots/p2-type-light.png` shows what one display face does.
- **Light mode is cool and thin:** `#f6f2f5` sits lilac beside the plum logo, three near-whites, hairlines without weight. Dark is better composed, which tells where the fix is.
- **Home is a list of links:** search, a ring, four tips, a stats line, chevrons. No greeting, nothing about today, no object to look at first.
- **The level glyph** (m5 05-bottles) fills a 16×28 bottle in the shade's colour: invisible for dark shades in dark mode, a brown lozenge in light.
- **Bottle rows lead with the P code** at 17/600, the least interesting fact.
- **The date input** is the UA control: "07/21/2026", centred, US order, taller on iOS.
- **Sheets are one shape on every device:** a bottom sheet across a 40rem column at 1440 is a phone pattern on a desk.
- **Dark-mode tips lose their silhouette** (One-Coat Black, Herb Your Enthusiasm in m7 dark-a).
- **Keep:** the tab bar, the ring and its hairline rail, one filled action, outlined chips, the builder's structure, the copy voice, the logo.

## 2. The v3 direction: the swatch book, lit

The bones stay: a nail tech's colour chart, every shade a painted tip on a quiet board. What changes: tips become objects under one light; the board becomes warm paper; four display roles get a face; Home becomes a shelf; the app gets three shells.

### 2.1 Display face: Fraunces, four roles only

**Fraunces**, variable, weight 600, optical size 144 set explicitly, SOFT 0, WONK 0. SIL OFL 1.1, self-hosting allowed: https://github.com/undercasetype/Fraunces and https://fontsource.org/fonts/fraunces. Vendor the Fontsource Latin variable file with `wght` and `opsz` only under `static/vendor/fraunces/` with the version in `VERSIONS.txt`; a `pyftsubset` to Latin + Latin-ext should land near 45 KB (the full Latin file I tested is 67 KB). Preload it, `font-display: swap`, fallback `ui-serif, Georgia, serif` with `size-adjust` so the greeting does not jump.

Why (evidence `shots/p2-type-*.png`, `shots/p5-home-390-fraunces-*.png` against `shots/p5-home-390-gloock-*.png`): Gloock has the best numeral but wraps the greeting at 390 and thins out in dark; Instrument Serif is the 2025 AI-page default and too light at 28px on plum; Bricolage and Newsreader are not distinct enough from SF to earn a download; Young Serif is heavy enough to fight the tips. Fraunces 600 at opsz 144 is warm without being cute and holds one line. The earlier rejection was Fraunces at 19px with SOFT on every row; none of that survives here.

| Role | Size/leading | Where |
|---|---|---|
| Greeting | 34/36 (40/42 at ≥1280) | Home |
| Shade title | 28/31 | Shade detail head, the Home hero |
| Wheel name | 22/24 on cards, 34/36 on the wheel page | |
| Hub and passport numbers | 56/56 on the ring, 28/28 on Home | tabular figures |

Never below 22px; never on a row, button, label, chip, tab, meta line or stack summary (`shots/p6-builder-panel-1440-dark.png` shows × and + glyphs looking wrong in Fraunces). `font-variation-settings: "opsz" 144` is explicit because Safari's automatic optical sizing maps 34px to the text cut. Everything else stays SF Pro on the existing scale.

### 2.3 Materials

Chrome is frosted, content is not: tab bar, stuck search bar, sheet footer and panel header use `--material` + `blur(20px) saturate(1.6)` + a 1px inner top highlight (`inset 0 1px 0 oklch(1 0 0 / .35)` light, `.08` dark) + the existing edge; opaque under `prefers-reduced-transparency`. ### 2.5 Shelf and rack

A rack is a horizontal `scroll-snap` list of `tip-l` with names under, standing on a **ledge**: a 1.5px `--line` rule across the full width with the contact shadows resting on it (`.rack .tip::before { bottom: -7px; height: 10px }`) and a 10px gradient of `--shadow-ink` at 8 percent beneath. ### 2.6 Holo, restrained

Foil stays on tips (`?hl` ring, save sweep), the logo, and now the **focus ring on tips and ring slots** (a 2.5px conic ring outside the die-cut edge; see the highlighted slot in `shots/p6-builder-panel-1440-dark.png`). Gradient text was tried on the passport number (`shots/p5-home-390-fraunces-light.png`) and fails: pale on paper, and the craft floor bans it. Nothing else is holo.

### 2.7 Motion

Named properties only; feedback 150ms, routine 200 to 250, overlays 320 to 380, the one authored moment 600; `cubic-bezier(.16, 1, .3, 1)` for arrivals, `--ease-in` for exits. Reduced motion: opacity only, 150ms.

1. Press `scale: .96` 150ms; rows wash instantly. Kept.
2. Overlays per shell (3.1): phone sheet 380 up, 240 down; modal fades with scale `.96` to 1 over 240; panel slides from the right 280.
3. **Add to collection**, the authored moment: the new bottle row's tip arrives from `scale .85, opacity 0` over 600ms on `linear(0, .4 7%, .8 15%, 1.04 30%, .98 45%, 1)` with one specular sweep (the band's position from -60% to 160% over 700ms). The same sweep on a saved ring slot and on the Home hero after "Another".
4. Row to detail: `@view-transition { navigation: auto }` with `view-transition-name: tip-{id}` on the row tip and the head tip (Safari 18.2+; plain navigation before).
5. Ring tap lifts the slot to 1.08 before the sheet. Kept.

Theme switch suppresses transitions for one frame (`chrome.js`). Nothing animates on load.

## 3. Responsive architecture: website view and app view

Three shells from one HTML, chosen by viewport width, never by user agent.

| Shell | Width | Nav | Overlays | Shade detail |
|---|---|---|---|---|
| **Phone** (app view) | < 700px | frosted bottom tab bar, large titles | bottom sheets | full page |
| **Rail** (iPad portrait, narrow windows) | 700 to 999px | 72px icon rail, tooltips on hover | centred modals, max 560px, radius 20 | full page |
| **Panel** (iPad landscape, Mac; website view) | ≥ 1000px rail + panel; ≥ 1280px 240px sidebar + panel | rail or sidebar with labels and a `/` hint, More and "Signed in as" at the foot | `#sheet` becomes a right-anchored modal panel, 400px (360 below 1280) | a non-modal `#panel` beside the list |

Evidence: `shots/p5-home-834-light-full.png`, `shots/p6-shades-panel-1024-ipad-light.png`, `shots/p6-shades-panel-1440-light.png`, `shots/p6-builder-panel-1440-dark.png`.

Mechanics: `body` gets `padding-inline-start` 0, 72 or 240 by media query; the tab bar is `display: none` from 700px; one `<nav class="side">` always rendered, labels hidden below 1280; content `max-width` 40rem on phone, none on rail, 1120px centred in the sidebar shell; hover only under `(hover: hover)`. Keyboard on the panel shell (`keys.js`, about 60 lines): `/` focuses search, `Esc` closes panel or sheet, `n` opens Add bottle when a shade is shown, arrows move the list selection, `Enter` opens it; the hint line at the foot of a list appears after the first `:focus-visible`.

### 3.1 HTMX overlays per shell

The one `<dialog id="sheet">` stays and CSS repositions it: phone as today plus drag-to-dismiss on the grabber (`sheet.js`, pointer events, release velocity decides, about 40 lines); rail `margin: auto; max-width: 560px; border-radius: 20px; max-height: 86dvh`, no grabber; panel `margin: 0 0 0 auto; height: 100dvh; width: 400px; border-radius: 0; border-left: 1px solid var(--line)`, a frosted sticky head with the title at 15/600 and a round close button, the footer sticky, the scrim at .25.

The shade detail does not use `#sheet`. Rows stay plain links with `data-panel`; `panel.js` (about 50 lines) intercepts the click only when `(min-width: 1000px)` matches, calls `htmx.ajax("GET", href + "?panel=1", "#panel")`, pushes the URL and marks the row `aria-current`. The server renders `shade_detail.html` without the base chrome when `panel=1` (one conditional around `extends`). Deep links to `/shades/{id}` on the panel shell render the list with the panel open; Back closes the panel. The builder uses `#sheet` everywhere, so on Mac it is the right panel beside the ring.

### 4.1 Bottle level: the ring arc

Evidence `shots/p3-level-*.png` (meter, arc, gauge, line in the shade colour; dark shades vanish in dark mode, the current glyph's flaw) and `shots/p3b-level-ink-*.png`. **The arc, in ink:** 20px, filled clockwise from twelve, readable for every shade in both modes; Low and Empty keep their word colour so colour is never the only carrier.

### 4.2 Date field

Evidence `shots/p4-date-*.png`. The overlay pattern: a field styled like every input (50px, radius 10, `--line-2`), a calendar icon, the value in words ("Today  26 Oct 2026", "21 Jul 2026  Tuesday", "Not yet" in `--ink-3` when empty), a chevron, and preset chips **Today**, **Yesterday**, and **Don't know** only on optional fields. The real `<input type="date">` covers the field at `opacity: 0; font-size: 16px; appearance: none` with `max` = today, so a tap opens the native wheel on iPhone and iPad and the popover on Mac. `date.js` (30 lines): on `change` format `valueAsDate` with `Intl.DateTimeFormat`, set `aria-pressed` on the matching preset; presets set the value in local time and dispatch `change`. Focus ring via `:focus-within`. Server validation unchanged plus "not in the future".
